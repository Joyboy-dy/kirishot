# Kirishot J2 « Usage quotidien » Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Kirishot from "capture works" into a daily tool: a polished selection screen, a shutter sound and flash, a floating thumbnail after each capture, and an annotation editor with the essential tools.

**Architecture:** Rust keeps the capture, the clipboard, the files and a new per-capture state machine (`shots`); two new pre-created webviews join the overlays: `thumbnails` (one non-activating window holding the stack) and `editor` (a normal window, reused). The editor draws with react-konva over a pure TypeScript document model; export redraws the same Konva scene at scale 1 and sends raw PNG bytes to Rust.

**Tech Stack:** Tauri 2.12, Rust 2024, React 19, TypeScript 5.9, Tailwind 4, shadcn (radix-nova), Vitest 5; new: `konva`, `react-konva`, `perfect-freehand`, `tauri-plugin-drag` (crate + `@crabnebula/tauri-plugin-drag`), `@radix-ui` tooltip via `radix-ui`, `windows` features `Win32_Media_Audio`, `Win32_UI_Shell`, `Win32_Graphics_Gdi`.

**Spec:** `docs/superpowers/specs/2026-11-02-kirishot-usage-quotidien-design.md` (binding for J2), on top of `docs/superpowers/specs/2026-11-01-kirishot-design.md`. Research: `docs/recherche-ux.md`.

## Global Constraints

- Language of the UI and of user-facing strings: French, through `src/i18n/fr.json` (front) and `src-tauri/src/messages.rs` (Rust). Code and comments in English, matching the existing code.
- Settings stay `version: 1`; new fields get defaults through the existing leaf-by-leaf `repair` and `validate` (spec § 6.1): `afterCapture.thumbnail: true`, `afterCapture.thumbnailSeconds: 6` (3, 6, 10 or `null`), `capture.magnifier: true`, `capture.sound: true`, `capture.flash: true`.
- Timings: 120–180 ms small state changes, 200–250 ms panels, enter `cubic-bezier(0.2, 0, 0, 1)`, exit ease-in, no bounce; everything off under `prefers-reduced-motion` (spec § 5).
- Contrast: 4.5:1 text, 3:1 icons and outlines (spec § 5).
- Every interactive element has `cursor: pointer`, disabled ones `not-allowed` (spec § 2.1).
- No GPL/LGPL/tldraw code is copied (`docs/recherche-ux.md`); code adapted from XenSnip (MIT) is credited in `THIRD_PARTY.md`.
- Every new Tauri command is listed in `src-tauri/build.rs` `AppManifest::commands` and allowed per window in `src-tauri/capabilities/*.json` with `allow-<command>`; `src/lib/bindings.ts` is regenerated by `cargo test` and committed.
- Writing files from Python on Windows: open with `newline=''` (CRLF breaks Prettier and rustfmt checks).
- `pnpm lint`, `pnpm typecheck`, `pnpm test`, `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test` stay green after every task.

## Review Focus

1. **Focus theft.** Clicking, hovering or dragging a thumbnail must never take the keyboard focus from the app the user is typing in (Word, a chat box): the next key still goes there.
2. **One automatic action per capture.** A capture whose thumbnail expires while its editor is opening, or which is closed by × right after expiring, must be saved/copied exactly once (never twice, never zero times when the setting asks for it).
3. **Global shortcuts while a Kirishot window has focus.** With the editor focused (it now stays open for minutes), Win+Shift+S must start a Kirishot capture, not Windows' tool (known J1 limitation, Task 1 diagnoses it).
4. **Large captures in the editor.** A 3840×2160 (or a 5120×1440) capture opens, pans, zooms and exports at full resolution without the canvas limit or a multi-second freeze; pixelate on a large area stays responsive.
5. **Several captures in a row.** Four quick captures: the stack shows 3 cards plus « +1 », each with its own countdown; the 4th enters when one leaves; a capture on the other monitor moves the stack there.
